# Coffee Orders Dashboard – Excel Project

This project is a complete **Coffee Orders Analysis Dashboard** built using Microsoft Excel.
It uses structured datasets and multiple supporting sheets to generate automated insights, charts, and KPIs.

## Project Files

### **1. coffeeOrdersData.xlsx**

This file contains the **raw dataset**, organized into three tables:

* **orders** – Order details such as date, quantity, product ID, customer ID
* **customers** – Customer information including name, email, country
* **products** – Product details including coffee type, roast type, size, unit price

### **2. coffeeOrdersDashboard.xlsx**

This is the **final dashboard workbook**, containing:

* **Dashboard** – The main interactive dashboard
* **TotalSales** – Pivot table for overall sales metrics
* **CountryBarChart** – Pivot table + chart for country-wise sales
* **Top5Customers** – Pivot table for identifying top customers
* **orders** – Cleaned orders data
* **customers** – Customer data
* **products** – Product details

---

## Dashboard Features

The main dashboard includes:

* **Total Sales KPI**
* **Total Orders KPI**
* **Top 5 Customers Table**
* **Country-wise Sales Bar Chart**
* **Interactive Filters (Slicers)** for:

  * Roast Type
  * Coffee Size
  * Country

The dashboard is fully automated using pivot tables and dynamic charts.
